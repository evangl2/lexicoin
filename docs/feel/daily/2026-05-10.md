### [🟡] ProgressionHUD level number lacks pop
- **What happens now**: When the user levels up, the level number in the HUD changes instantly without any visual flourish.
- **Why it feels off**: Missing overshoot/responsiveness. Important state changes should draw the eye and feel impactful, rather than just snapping to a new value.
- **Location**: `src/app/components/ui/shell/ProgressionHUD.tsx:50`
- **Proposed change**: Wrap the level number in an `AnimatePresence` and `motion.span` with `key={progressInfo.level}`. Use `initial={{ scale: 1.5, opacity: 0, color: '#D4AF37' }}`, `animate={{ scale: 1, opacity: 1, color: '#FFFFFF' }}`, `transition={{ type: 'spring', stiffness: 300, damping: 20 }}`.
- **Why this works**: A sudden scale-down and color flash (overshoot/secondary motion) grabs attention and celebrates the new level.
- **Confidence**: High

### [🟢] LevelUpOverlay transition arrow and new level appear statically
- **What happens now**: The `previousLevel → newLevel` text at the bottom of the LevelUpOverlay appears all at once with the rest of the modal.
- **Why it feels off**: Staging. Reading happens sequentially; showing the old level, then the arrow, then the new level tells a better story.
- **Location**: `src/app/components/ui/system/LevelUpOverlay.tsx:71-73`
- **Proposed change**: Wrap the `span`s in `motion.span` and add a stagger. `previousLevel` `animate={{ opacity: 1 }}`, arrow `animate={{ opacity: 1 }} transition={{ delay: 0.3 }}`, `newLevel` `animate={{ opacity: 1, scale: [1.5, 1] }} transition={{ delay: 0.6, type: "spring" }}`.
- **Why this works**: Staggering the reveal guides the user's eye and builds a tiny moment of anticipation before slamming the new level down.
- **Confidence**: High

### [🟡] SynthesisCircle status text changes abruptly
- **What happens now**: The small status text at the bottom of the SynthesisCircle updates instantly when the state changes.
- **Why it feels off**: Missing easing. Sudden text swaps feel unpolished and glitchy.
- **Location**: `src/app/components/ui/visual/SynthesisCircle.tsx:244`
- **Proposed change**: Wrap the text in `AnimatePresence mode="wait"` and a `motion.span` with `key={statusText}`, `initial={{ opacity: 0, y: 5 }}`, `animate={{ opacity: 1, y: 0 }}`, `exit={{ opacity: 0, y: -5 }}`, `transition={{ duration: 0.15 }}`.
- **Why this works**: A quick vertical fade-and-slide softens the transition and makes the text feel like an active readout panel.
- **Confidence**: High
