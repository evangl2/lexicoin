### [🟡] DynamicText fade-in is hardcoded and slow
- **What happens now**: The text opacity transition uses a simple, linear CSS `transition-opacity duration-200`, making it feel a bit sluggish and lacking the organic snap found in spring animations.
- **Why it feels off**: Using a static CSS duration rather than a spring makes the text arrival feel uniform and linear (easing principle). Easing is linear by default for standard `transition`.
- **Location**: `src/app/components/ui/text/DynamicText.tsx:90`
- **Proposed change**:
  - Switch from CSS transition to framer-motion `animate` with a spring, or simply use `motion.p` with `initial={{ opacity: 0 }}` and `animate={{ opacity: isFitting ? 0 : (style.opacity ?? 1) }}` and a quick spring transition instead of `transition-opacity duration-200`.
- **Why this works**: A spring-based opacity transition integrates better with the engine and feels snappier.
- **Confidence**: High

### [🟡] TieredText entry animation is too slow and lacks spring
- **What happens now**: The tiered text slowly slides up and fades in over `0.2` seconds linearly (`transition={{ duration: 0.2 }}`).
- **Why it feels off**: The linear 200ms duration feels slightly slow and lacks the overshoot/bounciness that gives UI elements weight (overshoot, easing principles).
- **Location**: `src/app/components/ui/text/TieredText.tsx:50`
- **Proposed change**: `transition={{ duration: 0.2 }}` → `transition={{ type: "spring", stiffness: 300, damping: 25 }}`
- **Why this works**: A snappy spring with slight overshoot adds energy to the text appearing, giving it more "pop".
- **Confidence**: High

### [🟡] ProgressionHUD XP/Stamina bar fill feels too loose

- **Why it feels off**: The low stiffness makes the bar slowly crawl to its new value, lacking the punchy responsiveness expected from gaining XP or consuming stamina (responsiveness and easing principles).
- **Location**: `src/app/components/ui/shell/ProgressionHUD.tsx:64, 82`
- **Proposed change**: `stiffness: 50, damping: 20` → `stiffness: 150, damping: 25`
- **Why this works**: Increasing stiffness makes the progress bar snap to the new value much faster while maintaining a smooth settle.
- **Confidence**: High
