# ADR-006: Centerpiece v4 —— 一副骨架 + 可插拔材质模型家族

> 状态: 现行 · 类型: 决策 · 更新: 2026-07-04(补充:光照系统重做 + 调参面板工作台化,见下方"2026-07-04 补充")
> 📖 人话: persona 的视觉跨度太大(宝石也要、蜡笔手绘也要),一个 shader 罩不住。方案:共享骨架 + 按"材质模型"切换,新设想=加一个模型,不碰旧的。

## 背景

Persona 视觉设想横跨两种渲染哲学:物理光照系(宝石/血肉/植物)与风格化系(儿童手绘/纸板/少女)。单一巨型 shader 覆盖两边会参数打架、复杂度失控(ADR-004 要防的泥潭);同时作者要求"未来可按新设想补充 shader"。另有 v3 的系统性缺陷需要架构级修复:光照在 gamma 空间计算(发闷根因)、预乘 alpha 双乘(边缘暗圈)、高度/法线资材矛盾无调理手段、硬编码视觉常数违反铁律一。

## 决策

1. **共享骨架**:坐标同步、五图资材契约、Mask 三路路由、发光 pass、preset/调试面板体系写一次,所有材质模型复用(实现为同一 CenterpieceDecal,fragment shader 可切换)
2. **v4 管线**(默认):反预乘修正 → sRGB→线性解码 → 光照计算全线性 → 曝光 → 色调映射(None/Reinhard/ACES)→ 编码回 sRGB;新增 matcap 环境反射(默认程序生成棚光,persona 可换 AI 生成的 matcap 贴图)与资材调理参数组(法线 X/Y 翻转、偏置校正、高度反转)
3. **材质模型可插拔**:preset 用 `materialModel` 声明;v4 首发两个——`PBR`(宝石/血肉/植物/金属)与 `Stylized`(手绘/纸板/少女:色阶柔光,无物理高光,效果主要靠烘焙贴图)
4. **扩展路径**:新 persona 设想若两个模型都罩不住 → 新增一个材质模型(经作者批准,ADR-004 流程),不修改既有模型,已调好的 persona 永不被新想法破坏
5. v3 fragment 原样保留,面板一键切换对比;验收后另行决定去留

## 理由

- 材质模型 = 有边界的增量,巨型 shader = 无边界的累积;前者的复杂度是 O(模型数),后者是指数
- 线性工作流 + tonemap 是"高光死白/中间调发闷"的架构级解法,调参绕不过去
- 资材调理参数把推理贴图的系统性误差(如法线 G 均值偏置)吸收在滑块层,不逼作者重新推理

## 后果

- 实现: `src/pixi/backgrounds/CenterpieceDecal.ts`(FRAG_WGSL_V4)+ 面板 V4 PIPELINE / ASSET CONDITIONING 分区 + preset 新增可选字段(全部向后兼容,旧 JSON 照读)
- **旧 preset 在 v4 下观感会变**(它们是在 gamma 空间管线上调的),需要作者一次集中调参重新定版
- 发光 pass 的硬编码常数(×5.0、0.015)已滑块化,默认值保持 v3 行为不变

## 2026-07-04 补充:光照系统重做 + 调参面板"工作台"化

按 [plan-centerpiece-workbench.md](../refactor-pixi/plan-centerpiece-workbench.md) 实施第一包,在 ADR-006 的骨架上扩展:

- **光照互动拆成两个独立选择题**:光源类型(平行光/点光)× 驱动方式(固定/自动公转/跟随鼠标/公转+鼠标混合),点光有位置+距离衰减,高光随光源在表面滑动
- **新增副光、浮雕投影、摇曳、鼠标接近发光**:副光职责=托暗部(仅参与漫反射,风格化模型下同样生效,故不列入 `DEAD_IN_STYLIZED`);浮雕投影沿光方向在高度图上采样遮挡;摇曳是三频正弦叠加的运行时光强调制;接近发光按鼠标到法阵中心的世界距离调制发光层强度——以上运行时调制量均不写回 `_params`,只在写 uniform 的最后一步相乘
- **视差可选跟随鼠标**(此前只能跟随光),复用同一套 fixed/orbit/mouse/mixed 驱动向量计算
- **旧参数修复**:菲涅尔幂滑块量程收窄到有效区间(俯视视角下高值≈无效,默认值 5.0 仍在新量程外,面板数值框会显示但滑块视觉呈满格,拖动后进入有效区,此为已知且接受的行为);"缝隙阴影"重定义为同时压暗漫反射与高光(此前只压高光,和"高度 AO"功能重叠);环境反射新增"反射均匀度"参数,修正此前非金属材质环境反射被菲涅尔项压制到接近不可见的问题
- **画质修复**(唯一改变默认画面的两处,已获作者批准):边缘裁切改用 `fwidth` 自适应过渡带(替代固定 ±0.008),任意缩放倍率下边缘保持约 1 像素柔和过渡;输出前加屏幕空间散列噪声去色带
- **V4Uniforms 扩容**:`uV4A`~`uV4D`(原有)之外新增 `uV4E`~`uV4J` 六组(点光/衰减/环境均匀度、点光位置+视差驱动+去色带强度、鼠标原始偏移、浮雕投影、副光颜色强度、副光方向),原计划预估四组,实际按"每组单一职责"原则拆到六组,均已在 WGSL struct / UniformGroup 初始化 / `_flushParams` 三处核对一致
- **调参面板改为"工作台"结构**:材质/光照两个页签(图层/演出页签占位,留给第二包);新增 Select/Toggle 控件类型与条件显示(如切到"固定"驱动才显示方位角);常用区、Ctrl+Z 撤销(50 步)、分区级恢复默认、全量重置二次确认、matcap 圆形缩略图网格(`src/assets/matcaps/` 文件夹自动上架,`matcap-registry.ts` 用 `import.meta.glob` 扫描)
- 所有新参数默认值均保持与实施前逐像素一致(除上述两处画质修复);v3 fragment 未改动一个字符
