# ADR-007: 记忆模型取代耐久度,复习融入核心玩法

> 状态: 现行 · 类型: 决策 · 更新: 2026-07-05
> 📖 人话: 卡片耐久度退役。防刷改用"重复组合无奖励"的经济规则;"词会损耗"的体验改由遗忘曲线驱动的记忆褪色承担。复习不做独立模式,靠奖励加权和 Echo 回放融进现有玩法。画布上位置永远归玩家,系统只改卡片外观。

## 背景

现行耐久度机制(合成扣耐久、重复合成恢复、归零删卡,见 `src/core/services/DurabilitySystem.ts`)的设计目的是防止玩家反复用同一个词刷合成。2026-07-05 设计讨论(作者 × Claude Fable 5)确认其三个问题:

1. **误伤好行为**:"同词 × 不同搭档"的广泛探索是搭配学习、是 GDD §1.2 第五条(词汇网络性习得)最希望的玩家行为,但按使用次数扣耐久把它和"同词 × 同搭档"的刷子行为一起罚了;
2. **违背第一哲学**:归零删卡让玩家亲手学会的词永久消失,与"正反馈优先"(GDD §1.2 第一条)冲突,且不符合记忆事实;
3. **保持循环缺失**:系统所有压力推玩家向前(新词/新合成/新魔典),没有力量拉玩家回访旧词;创作式编码再好,不检索也会遗忘。

## 决策

### 1. 耐久度退役,职责一分为二

- **反刷 → 新颖度经济**:重复的合成组合返回缓存结果(`SynthesisResult.cached` 已存在)且**不发任何奖励**;首次组合给全额奖励。辅以"每卡每日记忆增益封顶"。不物理销毁卡片。
- **损耗感 → 记忆褪色**(见下)。

### 2. 记忆模型:两字段 + 惰性计算

每卡(Sense × 玩家)只存两个字段,不记录操作历史:

```
stability: number        // 记忆稳定度,单位约等于"天"
lastRetrievalAt: number  // 上次成功检索时间戳
```

保持率 **R = exp(-(now - lastRetrievalAt) / stability)**,渲染/查询时惰性计算,无定时器。

检索事件发生时更新:

```
成功(质量 q): stability ×= 1 + k · q · (1 - R)   // (1-R) 项即间隔效应:快忘时回忆涨得多
失败:         stability ×= 惩罚系数(初值建议 0.7)
```

事件权重表(设计杠杆,数值可调):

| 事件 | 质量 q | 说明 |
|---|---|---|
| 魔典填词且评级 ≥ C | 按评级换算 | 最强检索:带产出、带评判 |
| 复习装置/Echo 答对 | 满 | 纯检索 |
| 合成中使用该卡 | 低,每卡每日封顶 | 主动使用但无检索压力 |
| 被动曝光(看到/hover) | **0** | 红线:被动曝光不算记忆练习 |

R 长期低于阈值 → 卡片进入**风化态**(褪成剪影、沉入档案,可通过再遭遇唤醒),**取代归零删除**。

### 3. 复习 = 三层结构,不做独立复习模式

独立"复习模式"即变相操练,违背 GDD §1.2 第二条。三层:

1. **无形层**(零新增):上表事件本身就是复习——正常游玩即在复习;
2. **引力层**(经济拉力):褪色卡(R 低)被成功使用时给显式加成(额外 Resonance/XP + 唤醒特效),让"翻旧卡"成为最优策略而非义务。**禁止**在魔典激活时高亮"哪些旧卡符合本题"(泄题),褪色卡自身的黯淡外观是唯一暗示;
3. **仪式层**(唯一新玩法,近零 AI 成本):**Echo 回放**——Library 抽旧魔典重开,题面在、玩家当年填的词被雾遮住,回忆自己的原答案。判定先做精确匹配(零 AI 调用),答出不同但合理的词可选走 AI 评判。挂接 GDD §2.6 已有的 Echo 每日限次。

温故炉(画布装置,投入褪色卡做创作式微检索)列为可选后续,前三层验证后再议。

### 4. 画布呈现设计律:位置属于玩家,外观属于系统

- **否决**按记忆状态自动分区的方案(如四象限:新词/记忆/复习/遗忘区)——位置一旦编码系统状态,卡片就会随状态迁移,空间记忆钩子("那个词在火山旁边")失效,记忆宫殿价值被摧毁;
- 记忆状态 → **卡片外观**(饱和→褪色→剪影),"遗忘区"自然涌现于玩家自己的布局;
- 全局记忆地图 → **记忆透镜**:按键进入滤镜视图(强记忆暗、褪色亮),相机层实现,不动位置数据;
- 分区 → **玩家自画**:玩家圈地命名("厨房""旅途"),系统只注解(如"该区 38% 正在褪色"),永不移动卡片;
- 本条是 Stage F 坐标契约的设计输入:**玩家摆放的卡片位置是神圣数据,持久化精度按学习功能对待**。

### 5. 评语预算倒挂

evaluate-grimoire 的 prompt 规格中写入:**评语长度与评级负相关**——S++ 一句赞叹;F/C 最丰盛(差在哪、差多远、什么语境下反而成立)。学习发生在 near-miss 处;失败给的是礼物,不是惩罚。

## 理由

- 两字段模型是 SM-2/FSRS 类算法的标准压缩:曲线位置不需要操作日志,(stability, lastRetrievalAt) 即充分统计量;实现量小于被删除的 DurabilitySystem;
- 新颖度经济精确打击"重复组合"而付酬"搭档探索",防刷与教学目标不再互相误伤;
- "位置归玩家"保住空间编码(位置法)这一画布独有的学习价值。

## 后果

- 待实施(次序参照 [strategic-command.md](../strategic-command.md) §2):卡片 schema 增两字段;DurabilitySystem 退役(合成扣耐久/归零删卡逻辑移除,保留 MessageBus 事件位);合成奖励接 `cached` 判断;三处检索事件挂钩;渲染层 R→外观映射(Stage F/K 输入);Echo 回放(Stage N 前后);
