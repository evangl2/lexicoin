### [🟢] Implement explicit bundle chunk splitting
- **Symptom**: Load times are slightly impacted because large external libraries (React, Framer Motion, Supabase, Dexie) are grouped inconsistently or in one large vendor chunk.
- **Location**: `vite.config.ts`
- **Root cause**: Vite defaults to basic chunking. Large dependencies should be explicitly split so the browser can cache them better and load them in parallel.
- **Suggested fix**: Add a `manualChunks` configuration in `vite.config.ts`'s `build.rollupOptions.output` block to separate `vendor-react`, `vendor-motion`, `vendor-db`, and `vendor-supabase`.
- **Expected gain**: Smaller initial JS payload, better long-term browser caching for dependencies that don't change often.
- **Fix risk**: Low

### [🟢] Optimize fonts.css to use font-display: swap consistently
- **Symptom**: Text might remain invisible while fonts load (FOIT - Flash of Invisible Text), especially noticeable on slow connections.
- **Location**: `src/assets/fonts/fonts.css`
- **Root cause**: Web fonts can block text rendering. Adding `font-display: swap` ensures the browser shows fallback text immediately and swaps in the web font once downloaded.
- **Suggested fix**: Ensure `font-display: swap;` is present in all `@font-face` declarations in `fonts.css`. (Note: This is actually already implemented in the file! I will just ensure it's documented as correct).
- **Expected gain**: Users can read text immediately without waiting for megabytes of fonts to download.
- **Fix risk**: Low

### [🟡] Large CJK font payloads
- **Symptom**: Initial load can be extremely heavy on network bandwidth, potentially freezing loading progress bars.
- **Location**: `src/assets/fonts/fonts.css`
- **Root cause**: The Asian fonts (Noto Sans/Serif SC and JP) are massive (17MB and 25MB). They are imported unconditionally in `fonts.css`.
- **Suggested fix**: Implement a programmatic lazy-loading strategy for these specific fonts. Instead of `@import` in CSS, load them via `AssetManager.ts` using the `FontFace` API only when the user selects that language.
- **Expected gain**: Saves ~65MB of network download on initial load for users not studying Asian languages.
- **Fix risk**: Medium
