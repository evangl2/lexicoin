### [🟢] O(N) Array Allocation in SceneManager

- **Root cause**: The `activeGrimoires` selector wraps an existing array reference `s.activeGrimoires` in `useShallow`. Because `s.activeGrimoires` is an array inside the Zustand store, using `useShallow` on it directly forces an O(N) iteration check to verify equality rather than doing a fast O(1) strict equality check. `useShallow` should only be used on dynamically created objects or arrays.
