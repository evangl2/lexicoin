### [🟢] Unnecessary re-renders from Zustand player selector
- **Symptom**: Unrelated components (`GrimoireSlot`, `DevConsole`) re-render unnecessarily when unrelated player properties like stamina or XP change.
- **Location**: `src/app/components/ui/grimoire/GrimoireSlot.tsx:35`, `src/app/components/system/DevConsole.tsx:119`
- **Root cause**: Components are using `useGameStore(s => s.player)` to extract a single property like `settings.learningLang`. Returning the entire `player` object causes a re-render anytime *any* player property changes.
- **Suggested fix**: Updated selectors to grab only the precise property needed (e.g., `useGameStore(s => s.player?.settings?.learningLang)`). For `DevConsole`, also updated cheat callbacks to use `useGameStore.getState().player` inside the click handler to avoid duplicate subscriptions.
- **Expected gain**: Eliminates over-rendering of multiple canvas slots on unrelated state changes (like stamina regen ticking).
