# 等级与游戏进度系统 (Leveling & Progression System)

Lexicoin 采用了一套多语言、本地化的独立进度系统，旨在分别追踪玩家在每一门具体学习语言上的成长，并根据成长动态调节合成难度和经验奖励。

## 1. 多语言独立进度 (Multi-Language Progression)
游戏摒弃了单一的全局账户等级，转而使用按具体学习语言（如英语、日语等）隔离的等级系统。

每门语言的进度状态均独立存储，相关逻辑位于状态切片文件 `createProgressionSlice.ts` 以及类型定义文件 `types/index.ts` 中。存储的状态包含了每门语言当前的等级（`level`，上限 100 级）、当级已积累的经验值（`xp`）、升级所需的动态阈值（`xpToNextLevel`）以及已收集的独特词条总数（`sensesCollected`）。这一切结构最终由持久化的全局对象挂载并管理。

## 2. 经验获取极致与注册表 (XPRegistry)
`XPRegistry.ts` 是一个中心化的服务模块，全权负责经验值（XP）的计算、校验和分发。

经验的获取来源和分配规则如下：
*   **首次发现新词 (`SENSE_COLLECTED`)**：当玩家合成出一个此前*从未见过*的词汇时触发。系统会根据该词条难度系数赋予极其丰厚的基础经验，这是升级的最主要途径。
*   **重复合成持有的词 (`SENSE_DUPLICATED`)**：当玩家合成出一个当前画布上*已经拥有*的词汇时，系统只会发放极少的象征性经验（约十分之一），以在机制上软性限制玩家通过无脑反复合成同一个词来刷级。
*   **找回曾遗失的词 (Recovery)**：如果玩家曾经发现过某个词，但该词的卡片因耐久度耗尽而碎裂丢失，再次合成它时可以重新获得卡片，但是出于平衡考虑，该操作**不提供任何经验值**。

一旦经验下发，将会调用内部服务触发验证算法，决定是否向全局广播 `LEVEL_UP` 事件。

## 3. CEFR 难度动态分发采样器 (LevelDistributionSampler)
随着玩家等级的提升，Lexicoin 会利用 `LevelDistributionSampler.ts` 服务模块按算法动态调节发给 AI 引擎的难度要求。

难度要求对应于 CEFR（欧洲共同语言参考标准，从 A1 到 C2）。分发器的采样规则会随玩家 `level`（语言等级）平滑过渡。例如：
*   在低等级时，系统 100% 确保要求大模型生成包含最基础词典难度的词条。
*   在高等级时，系统内置的 `LEVEL_CEFR_DISTRIBUTION` 矩阵会自动展开一个涵盖各种难度的权重比例（例如允许产出 C1 甚至 C2 难度的生僻词组）。
*   在极端或未配置的阈值情况下，采样器提供了一个安全保底机制，强制回退至最基础的 A1 难度以防止游戏崩溃。

这种动态生成的 `CEFRLevel` 约束随后会被投递至大模型的 Prompt 生成管线中，确保 AI 的最终产出严格契合玩家当前的语言水平。

## 4. 进度条界面 (ProgressionHUD)
位于主界面的前端组件 `ProgressionHUD.tsx` 会从全局状态中读取玩家当前选择的学习语言。系统利用 `selectors.ts` 文件中的 `selectLanguageLevelInfo` 取值器（Selector），将复杂的后端经验数据安全、无副作用地转换为纯粹的前端展示数据。

这确保了经验条的百分比推算、当前等级的动画刷新能够极为高效地运行，并规避了 React 重渲染时常见的无限循环陷阱。
