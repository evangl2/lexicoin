## 🗺️ 走查旅程地图

本手册按玩家真实系统体验顺序设计，分为以下线性阶段：

1. **Summoner 部署**：画布上的召唤原点
2. **Persona 绑定**：生成时的角色快照
3. **魔典生成 (Generate)**：AI 介入的第一阶段
4. **填词交互**：沉浸式卡牌拖拽与 UI 校验
5. **提交与评判 (Evaluate)**：AI 介入的第二阶段及重试循环
6. **结算核验 (Resolved)**：评分算法与数学模型验证
7. **魔典归档 (Archive)**：存储限制边界测试
8. **图书馆系统 (Library)**：成就兑现与进度累加
9. **Echo 机制**：内容闭合循环与每日边界测试
10. **超时机制 (Expiry)**：并行的自然散佚路径

> **优先级定义**：
> - 🔴 **P0**：阻断级障碍。失败则导致核心循环卡死，必须修复。
> - 🟡 **P1**：主要功能缺陷。体验受损但流程可继续。
> - ⚪ **P2**：视觉/边缘细节。视觉表现或非核心交互瑕疵。

| 优先级 | 验证点 | 结果 | 备注 |
|--------|--------|------|------|
| 🔴 P0 | 当所有槽位无任何 F 之后，自动触发进入 Resolved 状态，盖戳最终等级水印 | $\square$ Pass $\square$ Fail $\square$ Block | |

### 🧭 核心验证：数学模型手算比对
**规则回顾**：
原始分 = `SUM(所有非F槽分值) / 槽总数配置` （不扣除分母的错槽情况）。最终分 = `原始分 - 0.3 * 历史总F次数`。（S++=8, S+=7, S=6, A=5, B=4, C=3, D=2）。
等级阈值：`S++(6.8), S+(5.9), S(5.2), A(4.5), B(3.5), C(2.5), D(<2.5)`。

> **操作样例**：3 个槽位全部一次性放对神契合的词汇。返回 S++, S, A。
> **期望计算**：(8+6+5)/3 = 6.33 -> 无扣分 -> `S+级 (≥5.9)`

> **期望计算**：(3+4+5+3+4)/5 = 3.8。F惩罚扣除0.3 -> 3.5 -> `B级 (≥3.5, <4.5)`
